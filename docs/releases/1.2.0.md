# PC Recap 1.2.0

PC Recap now runs on Windows, macOS, and Linux. This update also separates active time from idle, locked, suspended, and unavailable time, adds optional computer performance context, and makes long archives faster and safer to back up.

## Downloads

- Windows 10/11 x64: `PC-Recap-1.2.0-Setup.exe`
- macOS 12 or newer, Apple Silicon: `PC-Recap-1.2.0-mac-arm64.dmg`
- macOS 12 or newer, Intel: `PC-Recap-1.2.0-mac-x64.dmg`
- Linux x64: `PC-Recap-1.2.0-linux-x64.AppImage` or `PC-Recap-1.2.0-linux-x64.deb`

Linux foreground tracking currently requires X11 and `xprop`. On Wayland, PC Recap opens normally and reports foreground tracking as unavailable instead of recording invented activity.

## New in 1.2

- Native foreground app collection for macOS and Linux X11
- Tracking Health diagnostics with clear collector and permission status
- Separate active, idle, locked, suspended, and unavailable states
- Optional CPU, memory, battery, and power context in recaps
- Canonical app identities that reduce duplicate app entries
- Daily backups, safer recovery, and merge previews
- Faster SQLite analytics for archives built to last for years
- Clearer times, chart tooltips, stat explanations, and recap wording

## Before installing

These beta packages are unsigned. Windows may show SmartScreen, and macOS may show Gatekeeper because the DMGs are not notarized. Each download has a `.sha256` file beside it so you can verify the package.

PC Recap stores activity on your computer. It has no account, desktop telemetry, cloud sync, or external AI calls.

Read the full [changelog](https://github.com/TheAgencyMGE/pc-recap/blob/main/CHANGELOG.md) or [report a problem](https://github.com/TheAgencyMGE/pc-recap/issues/new?template=bug_report.yml).
